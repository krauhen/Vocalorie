# Requests

Rough feature asks live here, one file per item. A file in this directory is a captured idea, not
a decision and not authorization to implement.

Lifecycle: captured here → promoted to an `openspec/changes/<id>/` proposal when chosen → the
backlog file marked `Status: promoted → openspec/changes/<id>` or deleted, since git holds the
history. Required behaviour is only ever specified in `openspec/specs/`; this directory never
becomes a second source of truth about it.
